# 📊 Customer Churn Analysis

## 📌 Overview

This project analyzes customer data to understand **customer churn behavior** and identify the factors that may influence customer retention.

The analysis combines **Python-based data analysis, SQL queries, and data visualization** to transform raw customer data into meaningful insights.

The goal is to answer questions such as:

* What percentage of customers have churned?
* Which customer groups have higher churn rates?
* Does customer tenure affect churn?
* Which customer characteristics are associated with churn?
* What patterns can help businesses improve customer retention?

## 🔍 Project Workflow

### 1. Data Loading

Loaded the customer dataset into Python using Pandas and examined the structure, columns, data types, and basic statistics.

### 2. Data Cleaning

Performed data preprocessing tasks such as:

* Checking for missing values
* Identifying duplicate records
* Checking data types
* Handling inconsistent values
* Preparing data for analysis

### 3. Exploratory Data Analysis

Performed exploratory analysis to understand customer behavior and identify patterns related to churn.

Analysis included:

* Overall churn distribution
* Customer demographics
* Tenure analysis
* Customer segmentation
* Churn across different customer attributes
* Comparison between churned and retained customers

### 4. SQL Analysis

Used **SQLite3** to perform SQL-based analysis and answer business questions using:

* `SELECT`
* `WHERE`
* `GROUP BY`
* `HAVING`
* `ORDER BY`
* Aggregate functions
* Conditional analysis
* SQL-based customer segmentation

### 5. Data Visualization

Created visualizations using **Matplotlib and Seaborn** to communicate important patterns and trends.

Visualizations included:

* Bar charts
* Count plots
* Histograms
* Distribution plots
* Comparative visualizations
* Churn-related analysis charts

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
```

### 2. Navigate to the project directory

```bash
cd Customer-Churn-Analysis
```

### 3. Install the required libraries

```bash
pip install pandas numpy matplotlib seaborn
```

SQLite3 is included with Python, so it generally does not require a separate installation.

### 4. Open the Jupyter Notebook

```bash
jupyter notebook
```

Open:

```text
notebooks/churn_analysis.ipynb
```

and run the cells sequentially.
